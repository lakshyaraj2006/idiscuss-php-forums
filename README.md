## 🚀 Core Features

| Feature | Description |
| :--- | :--- |
| **🔐 User Authentication** | Secure signup and login powered by bcrypt password hashing and persistent session management. |
| **🏷️ Categorized Discussions** | Structured topic forums covering core technologies such as Python, JavaScript, Django, and React. |
| **🧵 Interactive Threads** | Start discussion threads, track updated content, and browse topics seamlessly with thread navigation. |
| **💬 Community Solutions** | Post comprehensive answers to resolve questions with author attribution and formatted timestamps. |
| **🔍 Full-Text Search** | Instantly search threads by title and content with dynamic match counters and real-time feedback. |
| **📄 Smart Pagination** | Built-in pagination across thread listings and search results for fast browsing and smooth performance. |
| **🎨 Modern Responsive UI** | Clean, mobile-friendly design built with Bootstrap 4, interactive modals, and hero carousel sliders. |
| **🛡️ Clean URL Routing** | Extensionless, SEO-friendly endpoints configured via Apache rewrite rules in `.htaccess`. |
| **⚡ Flash Alerts System** | Centralized notification banners providing instant feedback for validation and user actions. |

---

## 🛠️ Tech Stack

- **Backend:** PHP 8.x (Native procedural PHP with prepared statements)
- **Database:** MySQL / MariaDB (Relational schema with InnoDB & full-text indexing)
- **Frontend:** Bootstrap 4.5.3, HTML5, CSS3, JavaScript, jQuery 3.5.1
- **Web Server:** Apache (via XAMPP / WAMP) with `mod_rewrite` enabled
